The directive #include <cctype> imports the C++ Standard Library header used for character classification and transformation.
The full form of <cctype> is C Character Type.

#include <string> is a preprocessor directive in C++ used to include the standard string library, which defines the std::string class.
Preprocessor directives are instructions given to the compiler before the actual compilation of code begins.

The #include <iostream> command tells the C++ compiler to include the standard input/output stream library so your program can read input and print.

The #include <algorithm> command includes the Standard Template Library (STL) Algorithm library in C++. It provides a massive collection of highly optimized, pre-written functions for data manipulation.
